# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

### Added

- Initial implementation of the timetable watch face for Second Movement.
- Configurable daily timetable with up to 127 periods.
- Different schedules for each day of the week.
- Custom start and end times for each period.
- Support for date-based timetable changes and alternating weeks.
- Automatic timetable updates based on local date and time.
- Countdown display for timetable transitions.
- Low-energy mode and wake-up handling.
- Configuration validation and error code display.
- Display handling for Custom LCD and other supported LCD types.

### Development

- Added development-only controls for testing timetable transitions.
- Added special time-jump tests for important schedule boundaries.

### Notes

- The project has not yet received its first stable public release.
- Development-only test controls must be disabled before normal distribution.
